- Run `repo-harness update` once from 0.32.x. The 0.33.0 candidate removes `~/.bun/bin/repo-harness` when it is the link into the installed package (Bun keeps the link of a bin name that the new version no longer declares), and leaves another file at that path with a notice. Update refreshes the files that it manages (skills, global working rules, agent fleet) from the package. It does not rewrite user-owned files: it lists each line in `~/.claude/CLAUDE.md`, `~/.claude/settings.json` and `~/.codex/AGENTS.md` that still calls `repo-harness <command>`. In each repository, `rh init` rewrites the package scripts that it manages (`check:brain`, `check:context-files`, `check:deploy-sql`, `sync:brain`), and `rh upgrade` reports other package scripts that call the retired command. `rh doctor` warns while `repo-harness` stays on PATH. Rollback: run `rh update --version 0.32.0`, or `bun add -g repo-harness@0.32.0` and then `repo-harness update`. The `rh` link then stays and runs 0.32.0 until a 0.33.0 update. (#2700)
