- The daily architecture freshness lane starts its 3 h lag clock at the first commit after the newest manifest commit that changes an input of a differing target: the archctx version, the architecture model, and the paths of the affected capabilities, or every capability-owned path for a whole-model target. Without such a commit the clock starts at the manifest commit. Under projection manifest v4 the manifest changes only with a render, so the former clock gave a false stale after a quiet period (#2375).
