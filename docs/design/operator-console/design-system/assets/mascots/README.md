# Mascots

Characters from the website mascot (Hook riding Donkey, with a carrot hanging from the fishing rod), drawn as pixel art. Each file is one SVG, `shape-rendering: crispEdges`, transparent background.

- Carrot buddy: 11 × 16 grid, four expressions (normal, happy, sleeping, alert). Leaves and body use the same greens and carrot orange as the logo.
- Donkey: 17 × 19 grid, side profile, long ears, dark mane, light muzzle, brown halter with a brass buckle. `donkey-happy` smiles with squinted eyes.
- Hook: a silver hook on a 10 × 14 grid. `hook-cap` wears a brown cap.
- Terminal: a terminal window on a 16 × 9 grid with a carrot-orange prompt.
- Second batch: Carrot buddy reading (holding a book with a blue cover), party (confetti), searching (magnifying glass), wrench; Donkey with bags (full-body side view on a 26 × 18 grid, carrying one blue and one orange bag with screens on its back, for Codex and Claude); Carrot on a line (a carrot hanging from a fishing rod); Bug (test failures); Disconnected cloud (data source unavailable).

For usage, see "Pixel characters" in the main README: scale by whole multiples, `image-rendering: pixelated`, `alt=""`, at most one per screen.
