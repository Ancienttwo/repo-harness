# Logos

- `repo-harness-carrot-mark.svg`: Pixel carrot logo on a 16 × 16 grid. Rounded ink (#14202E) square background, green leaves and carrot orange. Taken from the website's `public/favicon.svg` and kept as is: not redrawn, not recolored.
- Minimum size 16px. Keep pixels crisp when scaling up (`shape-rendering: crispEdges`).
- `repo-harness-carrot-mark-transparent.svg`: The same pixels without the ink square, on a 9 × 12 grid. Use this version in the interface sidebar and page header, so no black block appears on the light theme.
- Use the version with the background for the favicon and places where it must stand alone as a block. Neither version is color-inverted.
- Wordmark: `repo-harness` in Space Grotesk 700, lowercase, placed beside the logo. The gap equals half the logo's width.
