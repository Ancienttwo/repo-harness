# Historical: Engineer acquisition

The Engineer acquisition plane was removed in #773. The `engineer` CLI,
`engineer_*` MCP tools, principal registration and acquisition ledgers are
retired. This page is not an execution guide.

The GitHub issue and PR own task identity, claims, status and dependencies.
The operator can still read old Engineer bindings, receipts and work graphs.
It cannot create a binding or acquire work through the retired plane.

The earlier protocol is in Git history at
`1761db9ba37a2336e1518afa69c79f50253de8fa:docs/reference-configs/engineer-acquisition-cutover.md`.
