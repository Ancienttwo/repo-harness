## Design Decisions

- Exact 0.5.6 pins remain one source of truth across package dependencies,
  installed policy, downstream templates, provider adapters, and tests.
- Adoption identity is caller-supplied. The existing acceptance path emits
  `mode: adopt` only with that identity; ordinary calls remain `mode: apply`.
- Clean-room evidence is staged and atomically renamed only after success, so
  concurrent contract tests never observe a transient `running` document.
- The readback omits the projection receipt digest because that digest binds a
  random disposable workspace identity; the committed evidence retains the
  stable package, schema, capability, renderer, and worktree-match facts.
