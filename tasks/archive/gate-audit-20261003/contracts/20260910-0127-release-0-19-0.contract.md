## Why

`docs/CHANGELOG.md` has drifted 464 commits behind `main`, and the README
documents none of the five CLI command groups added since `v0.18.0`. Shipping
the release without closing that gap publishes a version whose public
entrypoints are undiscoverable and whose breaking host-readiness change (tmux
to herdr) is unannounced.

## Goal

`main` carries a coherent, reviewable `0.19.0` release candidate: version stamps
bumped, a `[0.19.0]` changelog section covering `v0.18.0..fd675687` with an
explicit breaking-changes callout, five README locales aligned with the current
command surface, and a release filing under `deploy/release-checklists/`.

## Scope

- In scope: `package.json` and `assets/skill-version.json` version stamps;
  `docs/CHANGELOG.md` `[0.19.0]` section; `README.md`, `README.zh-CN.md`,
  `README.ja.md`, `README.fr.md`, `README.es.md`;
  `deploy/release-checklists/260910-repo-harness-0.19.0.md`.
- Out of scope: any product source change; git tag creation; npm publish; global

- Taste constraints: changelog and README prose follow the existing terse
  declarative voice of the `[0.18.0]` section. Describe only capabilities

## Acceptance Notes (Human Review)

- Functional behavior: version stamps read `0.19.0` in both authorities;
  `docs/CHANGELOG.md` carries a `[0.19.0]` section with a `### Breaking`
  subsection naming seven downstream-visible changes and their operator actions;
  all five READMEs carry the two-layer structure at identical heading and
  code-fence counts; the release filing records prepared-not-published.
- Edge cases: the four localized READMEs were produced by parallel subagents and
  were treated as untrusted output. Structural parity, byte-identical mermaid
  source, diacritic integrity, and anchor/link resolution were verified per
  locale rather than assumed.
- Regression risks: `tests/readme-dx.test.ts` pins literal README strings but
  never resolves a documented `repo-harness <verb>` against the real command
  tree, which is why three nonexistent-command defects survived every green
  check on the first pass. They were caught by the acceptance gate and fixed;
  the coverage gap itself is not closed by this slice and is recorded as a
  follow-up.
