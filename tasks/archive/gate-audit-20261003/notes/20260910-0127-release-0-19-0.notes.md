## Design Decisions

- **Version `0.19.0`, not `1.0.0`.** Under 0.x cadence a minor may carry
  breaking behavior, and this repo already takes minors for new public surfaces
  (0.17.1 -> 0.18.0 for a protocol bump). `1.0.0` would promise a compatibility
  surface the range does not have: Refactor Mode activation is off, campaign and
  collaboration surfaces are authorization-gated, and the C9 multi-seat result
  is an accepted negative decision.
- **The changelog carries an explicit `### Breaking` subsection.** Seven
  downstream-visible changes land in this range, three of which need an operator
  action (`git rm --cached tasks/current.md`, `sprint migrate-schema`,
  regenerating capability blocks). Burying them inside Changed would make the
  upgrade path unreadable.
- **README is restructured into two layers rather than extended.** The product
  grew a program layer — authorization, budget ledger, lease, unattended
  controller — that does not fit as more rows in the existing feature table. A
  new `## Two Layers` section names the split, and `## Authorized Programs`
  documents the second layer's entry points. The session-contract path stays
  first so a solo-repo reader can stop reading after `## Task Workflow`.
- **The old `## Collaboration Canary` section folded into Authorized Programs.**
  The canary is evidence about the collaboration plane, not a peer feature of
  the operator board.

## Deviations From Plan Or Spec

- The plan scoped the README pass as an alignment update. Mid-task the owner
  reported that the product's shape had changed enough that much of the old
  README no longer applied, and chose a two-layer rewrite across all five
  locales. The four localized READMEs were therefore fully rewritten from the
  new English source rather than patched.
- `tests/readme-dx.test.ts` was added to `allowed_paths` as a precaution before
  the rewrite. It ended up needing no edit: the new README satisfies every
  pinned literal and placement invariant unchanged.

## Tradeoffs Considered

| Option | Decision | Reason |
|--------|----------|--------|
| Rewrite README.md only, defer the four locales | Reject | The owner chose full parity; a release that ships four stale entry points is worse than one that ships none |
| Relax `readme-dx` assertions to make the rewrite easier | Reject | The pinned literals are placement invariants, not wording locks; the rewrite satisfies them as written |
| Publish as part of this pass | Reject | The owner scoped this to reviewable-only; tag, npm publish, and runtime refresh stay a separate decision |
