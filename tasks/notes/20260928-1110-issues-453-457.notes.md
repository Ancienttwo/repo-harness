## Design Decisions

- #453 comment rule: `#` at the start of the item or after whitespace starts a comment, unless the
  item begins with a quoted scalar, in which case everything after the closing quote is dropped.
  `path#frag` and `"docs/a #b.md"` stay intact; `- # note` yields no path. The awk reader uses
  `close_at` because `close` is an awk builtin.
- #453 scope: the mutation guard (`parseAllowedPaths`), contract-run and both evidence producers
  had the same bug, so all five readers were fixed together to keep one scope decision.
- #457 root cause: ownership is captured only for paths a transaction created or already owned,
  and the update candidate calls `applyInstallProfile` with no transaction. The reporter's manifest
  had 4 entries and no agents, which matches this.
- #457 adoption guard: `applyInstallProfile(..., { agentFleetVerified })` adopts only when the
  caller's `install agent fleet` step returned ok. A successful fleet run leaves each target either
  byte-equal to the generated projection or byte-matched by the user-managed receipt; receipt-matched
  files are excluded. `rollbackInstallProfile` never adopts.
- #457 single reader: `readAgentFleetUserManagedReceipt` in `install-profile.ts` replaces the
  helper's inline `loadUserManagedReceipt`; the helper already loaded `install-profile.ts`. The
  read-only mirror in `check-agent-tooling.sh` is unchanged apart from its comment.
