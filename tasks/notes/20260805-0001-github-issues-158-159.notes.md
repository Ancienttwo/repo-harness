## Design Decisions

- Keep `scripts/emit-verify-evidence.ts` as the only emitter authority. The
  package helper resolves it through the declared package layout
  (`assets/templates/helpers/../../../scripts`) before considering the
  explicit `REPO_HARNESS_SOURCE_ROOT` override.
- Treat `checks_failed` as candidate evidence, not profile authority, only when
  Effective State proves every PreEdit target is canonically repo-contained
  and accepted by the active contract's `allowed_paths`. Operation readiness
  opens edit only; Stop/ship and every other blocker remain hard-blocked.
- Resolve contract path, `allowed_paths`, blocker, and repair readiness once in
  Effective State. The hook consumes that snapshot and performs no second
  workflow-authority read.
- Preserve `scripts/verify-sprint.sh` and
  `assets/templates/helpers/verify-sprint.sh` as byte-identical projections;
  `cmp` is part of the focused verification.

## Deviations From Plan Or Spec

- The first green attempt exposed two incomplete test fixtures (missing
  review-base policy and missing `## Allowed Paths` heading); production work
  paused, both authorities were reread, and the corrected fixtures were used
  for the retained red-green artifact.
- Security and architecture review then found a relative traversal escape and
  contradictory hook/readiness semantics. The bounded design was revised to
  canonicalize targets before scope matching and project the edit-only repair
  decision through Effective State; no new public configuration or dependency
  was introduced.

## Tradeoffs Considered

| Option | Decision | Reason |
|--------|----------|--------|
| Copy the emitter into `assets/templates/helpers/` | Rejected | Creates a second semantic source of truth and import drift. |
| Remove `checks_failed` from all hard blockers | Rejected | Would weaken stop/ship behavior and allow unrelated edits. |
| Re-derive repair authority in mutation guard | Rejected after review | Creates snapshot drift and contradicts public Effective State readiness. |
| Project contract-authorized repair through Effective State | Selected | Breaks the cycle while keeping one readiness and scope snapshot across hook, CLI, and MCP consumers. |
