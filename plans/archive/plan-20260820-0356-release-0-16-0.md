## P3 Decision

Version is `0.16.0`, the minor the 0.15.3 filing explicitly reserved: "0.16.0 is
reserved for the release where the kanban program lands complete, meaning WP2
(board) and WP3 (hook) ship together." Both landed in this range, so the program
is complete across all four blocks — WP1 lease store, the lease-protocol
hardening pass, the WP2 board projection, and the WP3 hook injection plus edit
gate. The consumer-visible surface grows by a new CLI verb and two new hook
behaviors, which is a minor, not a patch.

The candidate is metadata-only, so the release oracles are the repository's own
gates rather than a behavioral acceptance run: `bun run check:release`,
`bun run check:type`, the standalone full `bun test`, the deploy-SQL,
architecture-sync, and task-sync checks, and a packed-tarball smoke install.

Per the 2026-08-19 release-ritual lesson, this contract is right-sized against
the archived 0.15.3 contract rather than the generic template: `commands_succeed`
carries neither `check-architecture-sync.sh` nor `check:release` (both can never
pass inside the bounded verifier on this machine, because `scrubHarnessEnv()`
strips `REPO_HARNESS_NODE_BIN` while archctx requires Node >=24 <26 and the
protected PATH carries none), the two Change Assessment oracles are declared from
candidate prep, and the Task Profile is `docs-only`.
