## P3 Decision

Version is `0.15.3`, not `0.16.0`. The coordination plane is a program: WP1 and
its hardening pass shipped, but WP2 (board) and WP3 (hook) have not. Minting
`0.16.0` now would spend the version that should mark the kanban program
landing complete, and would signal a larger consumer-visible surface change
than this range actually delivers. `0.15.3` keeps the version line honest and
reserves `0.16.0` for the WP2+WP3 release.

The candidate is metadata-only, so the release oracles are the repository's own
gates rather than a behavioral acceptance run: `bun run check:release`,
`bun run check:type`, the standalone full `bun test`, the deploy-SQL,
architecture-sync, and task-sync checks, and a packed-tarball smoke install.
