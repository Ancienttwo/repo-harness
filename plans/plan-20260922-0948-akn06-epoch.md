## Goal
Implement AKN-06c Fleet service epoch and restart-safe browser observation identity. A service restart resets Fleet sequence; sequence alone must neither admit regressed observations nor permanently disable explicit recovery of an old Composer failure. Preserve original draft fences and readonly observation behavior.

## P1 / P2 / P3
P1: server.ts already owns one random serviceEpoch per start and increments sequence for serial Fleet collection. Repository snapshot2 carries the epoch, but nested Operator Fleet6 and the browser's main Fleet read omit it. Composer records only failed_sequence/sentAt; TaskDiff remount identity omits service identity. Existing associated readers have generation+abort guards. All provider calls in Fleet reviewing-card observation share one per-round limiter, and server Fleet observations serialize rounds; Collaboration reads stored projections without running providers. No new provider scheduler is justified here.
P2: server epoch + collected sequence -> redacted Operator snapshot -> strict browser decode -> Fleet state -> associated reads and Composer recovery. Same-epoch lower sequence must retain previous evidence as stale. New epoch accepts reset sequence and invalidates associated reader generations/TaskDiff lifetime. A saved draft retains its original Task/Claim fence; only the existing explicit rebind control may create a new message identity/fence. Capture the restart recovery failure on old production code before edits.
P3: bump Operator Fleet6 to7 with required service_epoch, and Repository snapshot2 to3 because its nested contract changes. Server is the epoch authority; projection requires it explicitly. Repository service_epoch is a deterministic projection from its nested snapshot, with an equality guard, removing the separate caller-supplied epoch argument. A shared pure UUID validator serves core Fleet, Repository and browser decoding; no random epoch generation in core or browser. No aliases, optional epoch, old protocol decoding or fallback. New epochs are opaque identities, not ordered values. Same-lifecycle cancellation already fences late packets; on accepted epoch change refresh scoped generations without resetting Decision cursor or remounting Composer. At10x load this adds no polling loop and at most one associated refresh on detected restart; existing bounded readers remain the capacity authority.
